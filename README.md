# Stellarity Pearl Restore

> [!WARNING]
> **AI disclaimer:** The code of this mod was written by AI (Claude, by Anthropic). The author directs what it does
> and tests it in game, but does not review the code itself. Please report problems as an issue.
>
> This mod is mainly made for private use. You are welcome to try it, but it comes without any promise of support.

A small addon for [Stellarity](https://modrinth.com/datapack/stellarity) that makes Endermen drop Ender Pearls
again. Minecraft 26.3 and 26.2, Fabric.

Stellarity changes the Enderman loot so that, outside the Nether and the End, they drop Chorus Fruit instead of
Ender Pearls. This mod swaps every Chorus Fruit an Enderman drops back into the same number of Ender Pearls, so
Looting keeps working. Everything else Stellarity adds to their loot stays as it is: Enderman Flesh, the Enderman
Hand and the Ender Eyes in the End.

It works on the drops themselves, so it does not matter in which order data packs load, and it keeps working when
Stellarity changes its loot table. Without Stellarity it does nothing.

## Installation

Needs [Fabric Loader](https://fabricmc.net/) and the [Fabric API](https://modrinth.com/mod/fabric-api). Download the
jar for your Minecraft version from the [releases](https://github.com/OctoMiku01/Stellarity-Pearl-Restore/releases)
and put it into the `mods` folder. On a server it is enough to install it on the server.
